# 安全清單

> 語言：中文（香港書面語）| [English](./security-checklist.md)

這是**產品清單**，不是審計意見。

## 必須向用戶展示

- 所有權：保留、放棄，或轉到 Safe／Timelock。
- 可增發或固定供應。
- LP 鎖定模式與剩餘時間（鏈上 `view`）。
- 稅與 max-tx 旗標，以及 OFT 轉帳維持 1:1。
- 有合約驗證時提供連結。

## 工程規則

- Custom error，不以 `require(string)` 作為用戶路徑。
- 雙層校驗（先 SDK，後合約）。
- 先模擬，再彈出錢包。
- 未知模組位元必須 revert。
- 主網在後續 phase 之前保持關閉。

## 不得宣稱

- 「已審計」
- 「不可能被 rug」
- 在仍只開測試網時宣稱主網可用
