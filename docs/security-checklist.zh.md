# 安全清單

> 語言：中文（香港書面語）| [English](./security-checklist.md)

此為**產品清單**，並非審計意見。本應用不託管私鑰或資產。請勿將產品描述為已經審計。

## 必須向使用者顯示

- 擁有權：保留、放棄，或轉至 Safe／Timelock。
- 可增發對固定供應。
- 流動性鎖倉模式及剩餘時間（鏈上 `view`）。
- 稅及單筆上限旗標，以及 OFT 轉帳維持 1:1。
- 合約驗證連結（如有）。

## 託管與私鑰

- 私鑰從不進入本站。簽署留在使用者錢包（RainbowKit／原生選擇器）。
- 觀察組及分享網址僅為公開地址。分享連結並非登入，亦非匯出私鑰。
- YSK Limited 並不為用戶資金營運託管人、排序器或提款隊列。

## RPC 與本機資料

- 自訂 RPC 網址及地址簿存於本瀏覽器（`localStorage`），不會上載至 YSK 伺服器。
- 公開節點輪詢可能失敗、限速或回傳過期資料。數字應視為未經核實。
- 「深度 USD」取自協議 TVL 端點及去中心化交易所報價，可能延遲、不全或錯誤。
- 外連上限只限制並行請求，並非安全邊界。

## 工程規則

- 自訂錯誤，使用者路徑不使用 `require(string)`。
- 雙層校驗（先 SDK，後合約）。
- 喚起錢包前先模擬。
- 未知模組位元會 revert。
- 主網 factory 欄位在明確部署前維持為零。

## 不得宣稱

- 「已經審計」
- 「無法被 rug」
- 保證收益、成交或年利率
- 在 factory 地址仍為零時宣稱主網就緒
