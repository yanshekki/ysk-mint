ETH / Base / Arb / BNB / AVAX / Solana / NEAR / Cardano, snapshotted
2026-08-26. Extra natives and stables for Polygon / OP / Fantom /

tokenRegistry.ts EXTRA. This is not the entire CMC universe. Named
files below are reused when the CMC id is known; others are cmc-{id}.png.
