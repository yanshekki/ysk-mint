# @ysk-mint/sdk

Enums, error codes, launch validation, and OFT helpers for [YSK Mint](https://mint.ysk.hk). Re-exports `@ysk-mint/config`.

```bash
npm install @ysk-mint/sdk
```

```ts
import { validateSymbol, ErrorCode } from "@ysk-mint/sdk";
```
