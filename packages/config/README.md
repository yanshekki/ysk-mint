# @ysk-mint/config

Chain registry, contract addresses, and numeric bounds for [YSK Mint](https://mint.ysk.hk).

```bash
npm install @ysk-mint/config
```

```ts
import { CHAINS, ChainKey, coreHoldingsChains } from "@ysk-mint/config";
```
